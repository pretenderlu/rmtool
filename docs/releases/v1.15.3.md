# rmtool v1.15.3

## English

- **Safer device switching and more stable connections:** Document lists and previews no longer show results from a previous connection, and pending deletions cannot carry over to another device. Improved handling of stalled operations; after a timeout, reconnect and check the device state before retrying.
- **Plugin checks and installation:** Prevented overlapping status checks and installation actions, restored the tap-to-turn status check button, and kept disabled plugins disabled during migration.
- **KOReader installation and removal:** Fixed false reports that KOReader is running which could block installation or removal, and improved recovery when replacing an existing installation fails.
- **Safer wallpaper replacement:** Uploaded images are verified before replacing wallpapers and carousel overlays. Existing restore backups are preserved instead of overwritten, with recovery files retained if restoration fails.
- **Download maintenance:** Maintained consistent download handling for Chinese UI, Pinyin input, and reading and note enhancements, retaining package verification, verified cache reuse, mirror fallback, and local package loading.

Windows x64 and macOS ARM64 application packages are available only from GitHub Releases. No firmware feature resource packages changed in this release.

## 中文

- **设备切换更安全，连接更稳定：** 文档列表和预览不再显示上一次连接的结果，待执行的删除操作不会转移到另一台设备。改进操作卡住时的处理；超时后请重新连接并检查设备状态，再决定是否重试。
- **插件检测与安装：** 防止状态检测与安装操作重复或重叠执行，修复点击翻页插件的检测按钮，并在迁移时保留插件的停用状态。
- **KOReader 安装与卸载：** 修复误报 KOReader 正在运行、导致无法安装或卸载的问题，并改进替换已有安装失败时的恢复处理。
- **壁纸安全替换：** 上传图片通过校验后才替换壁纸和轮播叠加图层；保留已有恢复备份，不再覆盖，并在恢复失败时保留恢复文件。
- **下载维护：** 统一维护中文界面、拼音输入、阅读增强和笔记增强的下载处理，保留资源包校验、已验证缓存复用、镜像回退和本地包导入。

Windows x64 与 macOS ARM64 应用安装包仅从 GitHub Releases 提供；本次没有更新固件功能资源包。
