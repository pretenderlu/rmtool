# rmtool v1.7.1

## English

- Fixed font upload on factory-reset and other fresh devices without an existing Chinese font.
- Uploading a font no longer changes the active system font automatically. Select **Set as system font** after upload to apply it.
- Existing fonts from earlier rmtool versions remain visible and manageable after upgrading.

Windows x64 portable and single-file packages, plus the macOS ARM64 application, are available from GitHub Releases.

## 中文

- 修复恢复出厂或全新设备在尚无中文字体时，首次上传字体失败的问题。
- 上传字体不再自动改变当前系统字体；上传完成后，请手动点击“设为系统字体”进行应用。
- 升级 rmtool 后，旧版本已上传的字体仍可正常显示和管理。

Windows x64 便携版、Windows x64 单文件版和 macOS ARM64 应用可从 GitHub Releases 下载。
