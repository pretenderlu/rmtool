# rmtool v1.16.1

## 中文

- **修复微信读书启动器在线安装：** 修复 v1.16.0 中启动器资源包无法进入 GitHub、腾讯云 COS 双源下载流程的问题。受影响用户可以直接使用此版本重新安装微信读书启动器；已经成功安装的微信读书官方应用、设备数据和其他插件不会受到影响。

Windows x64 与 macOS ARM64 应用安装包可从 GitHub Releases 下载。本次没有更新固件功能资源包，微信读书官方安装包仍始终直接从官方 CDN 下载。

## English

- **Fixed online WeRead launcher installation:** Fixed a v1.16.0 regression that prevented the launcher package from entering the verified GitHub and Tencent COS mirror download flow. Affected users can retry the WeRead launcher installation with this release; an already installed official WeRead application, device data, and other plugins are unaffected.

Windows x64 and macOS ARM64 application packages are available from GitHub Releases. No firmware feature resource packages changed in this release, and the official WeRead package continues to be downloaded directly from its official CDN.
