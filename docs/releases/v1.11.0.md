# rmtool v1.11.0

## English

- Added offline-verified support for beta firmware `3.28.0.169` on both Paper
  Pro and Paper Pro Move across all four firmware plugins: tap-to-turn pages,
  fast monochrome reading, the independent Simplified Chinese plugin, and
  offline Pinyin input.
- `3.28.0.169` keeps the internal version `20260806095513` shared with
  `3.28.0.166` and ships byte-identical stock translation catalogs, so the
  existing French-slot localization covers it unchanged. Every plugin package
  is still gated on the exact per-build xochitl SHA-256, and both new targets
  remain labelled offline verified pending real-device validation.

Windows x64 portable and single-file packages, plus the macOS ARM64 application,
are available from GitHub Releases.

## 中文

- 新增测试版固件 `3.28.0.169` 在 Paper Pro 与 Paper Pro Move 上的离线验证
  支持，覆盖全部四类固件插件：点击翻页、快速黑白阅读、独立简体中文和
  离线拼音输入。
- `3.28.0.169` 与 `3.28.0.166` 共享内部版本 `20260806095513`，且原生翻译
  目录逐字节相同，法语槽位系统汉化无需变更即可覆盖。所有插件包仍按
  每个构建的 xochitl SHA-256 精确门控；两个新目标在实机验证完成前继续
  标注“离线验证”。

Windows x64 便携版、Windows x64 单文件版和 macOS ARM64 应用可从 GitHub
Releases 下载。
