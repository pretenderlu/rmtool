# rmtool v1.16.9

## 中文

- **可选锁屏字体镜像：** 字体管理新增“为锁屏密码界面保留字体（写入 /data）”选项，默认保持原有行为。关闭后，系统字体只使用 `/home` 中的原文件，不再检查或占用 `/data` 字体镜像空间，并会安全清理 rmtool 管理的旧镜像。
- **统一相关流程：** 设为系统字体、旧版字体迁移和 RM1/RM2 中文兜底字体安装均遵循同一选项；界面会明确提示锁屏支持与 `/data` 空间限制。
- **安全性：** 保留字体哈希校验、空间检查、所有权判断和失败回滚；EPUB-only 字体不受该系统字体选项影响。

Windows x64 与 macOS ARM64 应用安装包从 GitHub Releases 提供。

## English

- **Optional lock-screen font mirror:** Font Manager now offers “Keep the font for the lock-screen passcode screen (write to /data)”, enabled by default for backward compatibility. When disabled, the system font uses its `/home` source only, skips `/data` mirror capacity checks, and safely removes rmtool's old managed mirror.
- **Consistent related flows:** System-font activation, legacy-font migration, and the RM1/RM2 CJK fallback font all follow the same option, with explicit UI warnings about lock-screen support and `/data` capacity.
- **Safety preserved:** Font hashes, capacity checks, ownership checks, and failure rollback remain enforced; EPUB-only fonts are unaffected by this system-font option.

Windows x64 and macOS ARM64 application packages are provided through GitHub Releases.
