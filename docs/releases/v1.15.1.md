# rmtool v1.15.1

## English

- **AppLoad startup fixed:** AppLoad-only installations now load correctly after a manual device restart.
- **Direct repair for affected installs:** rmtool detects installations created by the previous version and offers a **Repair and enable AppLoad** action without requiring manual cleanup.
- **Better diagnostic compatibility:** Device diagnostic bundles now collect resource information correctly on supported reMarkable systems.

Windows x64 and macOS ARM64 application packages are available from GitHub Releases. No firmware resource packages changed in this release.

## 中文

- **修复 AppLoad 启动问题：** 仅安装 AppLoad 时，设备手动重启后现在可以正常载入。
- **受影响安装可直接修复：** rmtool 会识别上一版本产生的安装，并显示“修复并启用 AppLoad”，无需用户手动清理。
- **改进诊断日志兼容性：** 支持的 reMarkable 设备现在可以正确采集磁盘与内存信息。

Windows x64 与 macOS ARM64 应用安装包可从 GitHub Releases 下载；本次没有更新固件功能资源包。
