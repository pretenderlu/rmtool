# rmtool v1.8.0

## English

- Added direct AppLoad and KOReader installation for exactly supported stable
  firmware, without requiring Vellum.
- AppLoad and KOReader are downloaded from their official GitHub Releases and
  verified before installation; matching official ZIP files can also be loaded
  locally.
- Existing KOReader installations can be migrated with user data preserved, or
  fully cleaned before a fresh installation.
- Fixed a Windows packaging issue that could leave KOReader on a blank screen
  after launch.
- The 3.28 beta firmware series remains unsupported by this installer.

Windows x64 portable and single-file packages, plus the macOS ARM64 application,
are available from GitHub Releases.

## 中文

- 为精确支持的正式版固件增加 AppLoad 与 KOReader 直接安装功能，无需安装
  Vellum。
- AppLoad 与 KOReader 从各自官方 GitHub Release 下载并校验，也可加载用户
  已下载的匹配官方 ZIP。
- 检测到旧版 KOReader 时，可保留用户数据进行迁移，也可彻底清理后全新安装。
- 修复 Windows 打包导致 KOReader 启动后白屏的问题。
- 本安装器暂不支持 3.28 系列测试版固件。

Windows x64 便携版、Windows x64 单文件版和 macOS ARM64 应用可从 GitHub
Releases 下载。
