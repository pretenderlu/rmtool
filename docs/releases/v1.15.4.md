# rmtool v1.15.4

## English

- Plugin recovery: Detect all plugins now checks whether a damaged installation can be repaired and explains why recovery may be blocked.
- Repair and reinstall: Eligible rmtool installations can be rebuilt from verified packages, retaining a backup, plugin switch states, settings, fonts, and books.
- Safety retained: Package and firmware checks remain strict. Failed repairs keep startup protection enabled; successful repairs require a manual restart as instructed.

First-version limits: automatic repair is unavailable for some old or mixed installations and installations with enabled Pinyin, AppLoad, or KOReader companion programs. This recovery flow has not yet been tested on a real device. If repair fails or its outcome is uncertain, keep the backup and diagnose before restarting.

Windows x64 and macOS ARM64 applications are available from GitHub Releases. Firmware feature packages are unchanged.

## 中文

- 插件恢复检测：“检测全部插件”现在会判断损坏的安装能否修复，并说明无法恢复的原因。
- 修复并重装：符合条件的 rmtool 安装可使用已验证的新包重建，保留原安装备份、插件开关状态、设置、字体和书籍。
- 保留安全校验：资源包与固件仍严格匹配。修复失败时保持启动保护；成功后按提示手动重启。

首版限制：部分旧安装、混合安装，以及启用了拼音输入法、AppLoad 或 KOReader 配套程序的组合，暂不支持自动修复。本次恢复流程尚未实机验证。修复失败或结果不确定时，请保留备份，先排查再重启。

Windows x64 与 macOS ARM64 应用安装包从 GitHub Releases 下载。本次未更新固件功能资源包。
