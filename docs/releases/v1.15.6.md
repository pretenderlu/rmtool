# rmtool v1.15.6

## English

- Stable firmware 3.28.0.172 now supports Native Simplified Chinese, offline Pinyin input, and tap-to-turn on Paper Pro, Paper Pro Move, Paper Pure, reMarkable 1, and reMarkable 2.
- Reading Enhancements, Note Enhancements, and Fast Monochrome remain available on the color Paper Pro and Paper Pro Move.
- Package selection continues to match the connected device and firmware exactly.

Paper Pure, reMarkable 1, and reMarkable 2 support is verified against official firmware images and awaits broader real-device feedback. AppLoad and KOReader remain unavailable on firmware 3.28.0.172 pending upstream support.

Windows x64 and macOS ARM64 application packages are available from GitHub Releases. Firmware feature packages are available from both GitHub and Tencent Cloud COS.

## 中文

- 正式版固件 3.28.0.172 现已在 Paper Pro、Paper Pro Move、Paper Pure、reMarkable 1 和 reMarkable 2 上支持原生简体中文、离线拼音输入和点击翻页。
- 阅读增强、笔记增强和快速黑白继续面向彩屏 Paper Pro 与 Paper Pro Move 提供。
- rmtool 仍会精确匹配当前设备与固件，不会跨机型安装插件包。

Paper Pure、reMarkable 1 和 reMarkable 2 已通过官方固件离线验证，仍需更多真机反馈。AppLoad 与 KOReader 暂不支持固件 3.28.0.172，需等待上游适配。

Windows x64 与 macOS ARM64 应用安装包从 GitHub Releases 提供；固件功能资源包同时提供 GitHub 与腾讯云 COS 两个下载源。
