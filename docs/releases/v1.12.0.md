# rmtool v1.12.0

## English

- Added one-click migration of verified shared-Xovi firmware-upgrade residue.
  The renamed toolbox entry "Legacy plugin migration/cleanup" now detects the
  exact feature states left behind by a firmware update and migrates every
  enabled feature onto the current firmware's exact packages in a single
  staged transaction that preserves each feature's enabled state; the Vellum
  cleanup panel is unchanged.
- Migration stays strictly gated: every enabled feature must have an exact
  package for the current firmware, the residue must verify against the old
  firmware's built-in manifests, xochitl must not currently have it loaded,
  and the device still needs a manual reboot after the transaction.
- Residue verification now also recognizes trees deployed by pre-release
  development builds: when identity, runtime files, feature states, and the
  marker itself still match the published manifests byte-for-byte, an
  unreleased launcher/drop-in generation no longer blocks cleanup or
  migration. Everything present on the device must still hash-match the
  published packages, and cleanup/migration always rebuild those two files
  from the current templates, so the tolerated variant never executes again.
- Per-feature firmware-residue states in the plugin pages use the same
  tolerant verification, so cleanup after an upgrade works from any feature
  page even for development-era deployments.

Windows x64 portable and single-file packages, plus the macOS ARM64 application,
are available from GitHub Releases.

## 中文

- 新增已验证共享 Xovi 固件升级残留的一键迁移。工具箱入口更名为“旧版插件
  迁移/清理”，可精确识别固件升级遗留的功能状态，并在一次分阶段事务中把
  所有已启用功能迁移到当前固件的精确包，同时保留各自的启用状态；原有的
  Vellum 清理面板保持不变。
- 迁移保持严格门控：每个已启用功能都必须有当前固件的精确包，残留必须通过
  旧固件内置清单验证，xochitl 未加载该状态，事务完成后仍需手动重启设备。
- 残留校验现在也能识别发布前开发版构建部署的目录：当身份、运行时文件、
  功能状态与标记本身仍与已发布清单逐字节一致时，未发布的启动脚本/开机
  单元变体不再阻断清理或迁移。设备上存在的每个文件仍必须与已发布包哈希
  一致，且清理/迁移始终按当前模板整体重建这两份文件，被宽容的变体不会
  再次执行。
- 各插件页的固件残留状态同样采用宽容校验，即使是开发期部署，升级后也能
  从任意功能页完成清理。

Windows x64 便携版、Windows x64 单文件版和 macOS ARM64 应用可从 GitHub
Releases 下载。
