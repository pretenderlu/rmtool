# rmtool v1.12.0

## English

- Added unified **Reading enhancements** for exact Paper Pro and Paper Pro
  Move 3.27/3.28 firmware builds. One native device Settings page now controls
  tap-to-turn, fast monochrome reading, periodic full refresh, and
  chapter-boundary refresh.
- Added safe migration and repair for verified older tap-to-turn and
  fast-monochrome installations, including residue left by a firmware update.
  Enabled features and other rmtool plugins are preserved where validation
  succeeds.
- Move 3.27.3 is device verified. The other thirteen supported targets are
  offline verified against their exact official firmware. Installation and
  removal still require a manual device restart.

Windows x64 portable and single-file packages, plus the macOS ARM64 application,
are available from GitHub Releases.

## 中文

- 为 Paper Pro 与 Paper Pro Move 的精确 3.27/3.28 固件新增统一的**阅读增强**。
  设备原生设置页可直接控制点击翻页、快速黑白、周期整屏清屏和按章节清屏。
- 新增旧版点击翻页、快速黑白及固件升级残留的安全迁移与修复；通过校验时会
  保留原有启用状态和其他 rmtool 插件。
- Move 3.27.3 已通过真机验证，其余 13 个目标均完成官方固件离线验证。
  安装、修复和停用后仍需从设备菜单手动重启。

Windows x64 便携版、Windows x64 单文件版和 macOS ARM64 应用可从 GitHub
Releases 下载。
