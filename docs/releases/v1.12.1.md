# rmtool v1.12.1

## English

- Fixed native Simplified Chinese installation on supported 3.28 beta builds
  whose current xochitl legitimately reuses an older verified French
  translation carrier.
- Device-side translation hash validation remains enforced. Ambiguous or
  mismatched devices are still blocked before installation.

Windows x64 portable and single-file packages, plus the macOS ARM64 application,
are available from GitHub Releases.

## 中文

- 修复部分受支持的 3.28 测试版固件无法安装原生简体中文的问题。这些固件的
  当前 xochitl 会正常复用已经验证的旧版法语翻译载荷。
- 设备端翻译文件哈希校验仍然严格执行；存在歧义或不匹配的设备仍会在安装前
  被阻止。

Windows x64 便携版、Windows x64 单文件版和 macOS ARM64 应用可从 GitHub
Releases 下载。
