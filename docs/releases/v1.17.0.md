# rmtool v1.17.0

## 中文

- **一键反馈问题**：报错弹窗新增“反馈问题”按钮，会自动打开诊断日志导出并引导完成采集、确认、保存诊断包；最后可“发送到邮箱”或前往 GitHub 提交问题。设备未连接时也能生成只包含电脑端信息的诊断包。
- **操作不再卡界面**：同步时间、设置时区、重启、开启 Wi-Fi SSH、提升前光亮度改为后台执行，连接异常时 60 秒内报错，不再让窗口长时间无响应。
- 内部结构整理，插件资源包的下载、缓存和校验逻辑统一，行为与校验规则不变。

## English

- **One-click problem reports**: Error dialogs now have a "反馈问题" (Report problem) button that opens diagnostics export and guides you through collecting, reviewing and saving a bundle, then sending it by email or opening a GitHub issue. Without a device connection, a PC-only bundle can still be created.
- **No more UI freezes**: Sync time, set time zone, restart, enable Wi-Fi SSH and increase front-light brightness now run in the background and fail within 60 seconds on a broken connection.
- Internal cleanup unifies plugin package download, caching and verification; behavior and verification rules are unchanged.
