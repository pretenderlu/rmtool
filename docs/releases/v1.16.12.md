# rmtool v1.16.12

## 中文

- **修复字体操作引起的挂载错误：** 字体及配置仅保存在 `/home` 时，上传、应用和删除不再执行多余的根分区重挂载，避免因此触发 `mount point is busy`。
- **修复插件安装被挂载状态阻止：** 共享插件安装和回滚保留根分区原有的只读或可写状态，避免对原本已可写的根分区强制切换为只读，导致原生简体中文、拼音输入法等安装失败。
- **确认无锁屏字体路径：** 关闭“为锁屏密码界面保留字体”后，自定义系统字体和中文兜底字体均使用 `/home`，不再按 `/data` 剩余空间限制字体；此前由 rmtool 管理的锁屏字体镜像仍会安全清理。

本次为应用修复，不改变现有设备和固件支持范围。Windows x64 与 macOS ARM64 安装包见下方附件。

## English

- **Fixed unnecessary root remounts during font operations:** Uploading, applying, or deleting fonts and configuration stored entirely under `/home` no longer remounts the root filesystem, avoiding related `mount point is busy` errors.
- **Fixed plugin installation failures caused by root mount handling:** Shared plugin installation and rollback preserve the root filesystem's original read-only or writable state instead of forcing an already-writable root read-only. This addresses failures affecting Native Simplified Chinese, Pinyin input, and other shared plugins.
- **Verified the home-only font path:** With lock-screen font support disabled, custom system fonts and the Chinese fallback font use `/home` without `/data` font-capacity checks. Previously managed lock-screen font mirrors are still cleaned up safely.

This application patch does not change device or firmware support. Windows x64 and macOS ARM64 packages are available below.
