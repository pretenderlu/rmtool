# rmtool v1.21.0

## 中文

- 为 Paper Pure、reMarkable 1、reMarkable 2 的 3.29.1.0 正式版提供原生中文、拼音和独立点击翻页适配。
- 新增这三款设备的原生文档传输、扫码传输和 AppLoad/KOReader 安装，支持全新安装和从 .172/.153 固件升级迁移。
- 保留 RM1 的 home 运行时、RM2 的 data 布局及存储安全边界，不开放彩色设备专属功能。
- 新包均完成完整 QML 回放、ABI 和确定性构建检查；各机型与功能仍需分别真机验收。

## English

- Add native Chinese, Pinyin, and standalone tap navigation for Paper Pure, reMarkable 1, and reMarkable 2 on stable 3.29.1.0.
- Add native document transfer, QR reception, and AppLoad/KOReader installation for these devices, with clean installation and migration from .172/.153.
- Preserve RM1's home runtime, RM2's data layout, and storage safety boundaries without exposing color-only features.
- Validate all new packages with full QML replay, ABI checks, and deterministic rebuilds; each device and feature still requires individual hardware acceptance.
