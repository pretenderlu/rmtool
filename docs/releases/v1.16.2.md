# rmtool v1.16.2

## 中文

- **彩色快刷减少翻页残影：** Paper Pro 与 Paper Pro Move 的 3.28 系列阅读增强改用经过 Move 3.28.0.172 实机验证的全窗口 Animation 刷新，消除原先混合刷新区域产生的短暂翻页残影。
- **明确彩色质量取舍：** 彩色快刷保留低质量彩色并提升响应，但颜色质量会降低，也可能累积彩色残影；需要更高色彩质量时请使用普通模式。提笔书写时会自动退出全窗口快刷，保持原生手写路径。
- **旧版安全更新：** v1.16.0/v1.16.1 用户连接设备并检测后，可直接执行修复更新到最新版；已安装功能状态会保留。

更新后的阅读增强资源覆盖已支持的 Paper Pro 与 Paper Pro Move 3.27/3.28 正式版及测试版固件；3.27 保持原刷新实现。本次变更已完成 16 个精确固件目标的离线编译与重放验证，Move 3.28.0.172 已完成实机验证。

Windows x64 与 macOS ARM64 应用安装包可从 GitHub Releases 下载；阅读增强资源同步发布至 GitHub 与腾讯云 COS。

## English

- **Reduced page-turn ghosting in color-fast mode:** Reading Enhancements on Paper Pro and Paper Pro Move 3.28 firmware now uses the full-window Animation path validated on a Move running 3.28.0.172, removing the short-lived page-turn ghosting caused by mixed refresh regions.
- **Clear color-quality trade-off:** Color-fast retains lower-quality color with a more responsive refresh, but color fidelity is reduced and color ghosting may accumulate. Use normal mode when higher color quality matters. Pen proximity automatically suspends the full-window override and preserves the stock handwriting path.
- **Safe update from earlier releases:** v1.16.0/v1.16.1 users can detect the device and apply the repair update to the latest Reading Enhancements package directly while preserving enabled feature state.

The updated Reading Enhancements resources cover the already supported Paper Pro and Paper Pro Move stable and beta 3.27/3.28 firmware targets; 3.27 retains its existing refresh implementation. All 16 exact firmware targets passed offline compile and replay validation, and Move 3.28.0.172 passed real-device validation.

Windows x64 and macOS ARM64 application packages are available from GitHub Releases. Updated Reading Enhancements resources are published to both GitHub and Tencent COS.
