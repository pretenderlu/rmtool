# rmtool v1.6.0

## English

- Added an independent Simplified Chinese plugin for exact Paper Pro and
  Paper Pro Move firmware builds. It preserves French and includes a guided
  migration path from the earlier French-slot localization.
- Unified native Chinese, tap-to-turn, and Fast Monochrome Reading on rmtool's
  shared plugin runtime. Historical rmtool Vellum packages can be removed with
  one click before switching to the new runtime.
- Improved system-font handling: the active font is stored under `/data`, works
  on the passcode screen, and can be migrated from the earlier root-partition
  layout without re-uploading it.
- Added Paper Pro 3.28.0.166 localization, tap-to-turn, and Fast Monochrome
  Reading resources. Paper Pro Move 3.28.0.166 remains unavailable until an
  official firmware package can be verified.

Feature resources are published to Tencent COS with GitHub fallback. Windows
x64 and macOS ARM64 application downloads remain available only from GitHub
Releases.

## 中文

- 为精确匹配的 Paper Pro 与 Paper Pro Move 固件新增独立“简体中文”插件，
  保留法语，并提供从旧版法语槽位汉化迁移的安全流程。
- 独立中文、点击翻页和快速黑白阅读统一使用 rmtool 自有的共享插件运行时；
  切换前可一键清理历史 rmtool Vellum 功能包。
- 改进系统字体管理：当前字体保存到 `/data`，密码锁屏也能正常显示，并可从
  旧版根分区字体方案直接迁移，无需重新上传。
- 新增 Paper Pro 3.28.0.166 的汉化、点击翻页和快速黑白阅读资源。Paper Pro
  Move 3.28.0.166 将在官方固件包可验证后再提供。

功能资源发布到腾讯云 COS，并以 GitHub 作为备用源；Windows x64 与 macOS
ARM64 应用安装包仍仅通过 GitHub Releases 发布。
