# rmtool v1.7.2

## English

- Fixed an issue where an uploaded font could fail to become the system font and the device continued using the stock Noto font.
- Fonts stored in rmtool's font repository can now be selected normally while preserving activation validation and automatic rollback.

Windows x64 portable and single-file packages, plus the macOS ARM64 application, are available from GitHub Releases.

## 中文

- 修复已上传字体无法设为系统字体、设备仍继续使用原生 Noto 字体的问题。
- rmtool 字体仓库中的字体现在可以正常切换，同时继续保留应用校验与失败自动回滚保护。

Windows x64 便携版、Windows x64 单文件版和 macOS ARM64 应用可从 GitHub Releases 下载。
