# rmtool v1.16.0

## 中文

- **荧光笔中文精确取词**：Paper Pro 与 Paper Pro Move 3.28.0.172 的阅读增强可按中文字符边界精确选择，同时保留英文单词扩展和其他原生手势。
- **微信读书在线安装**：rmtool 可在受支持的 Paper Pro 与 Paper Pro Move 3.28 系列固件上，从微信读书官方 CDN 在线安装或修复 RemarkableWeRead v1.0.0；官方安装包不会打入 rmtool，也不会由 rmtool 镜像。
- **微信读书启动器**：设备设置中新增单一入口，可按书选择普通、彩色快刷或黑白快刷，并可为两种快刷模式独立设置定期完整刷新页数。
- **阅读快刷整合**：阅读增强的全局开关只负责授权，具体刷新模式由每本 PDF/EPUB 独立选择。
- **插件更新识别优化**：rmtool 管理的共享 Xovi 插件会写入并校验结构化安装凭据。本地实机测试版本可以安全更新，不再要求为每次测试 revision 追加硬编码指纹，同时仍严格验证文件路径、内容、权限与运行时身份。

rmtool 仅为 **3.28 系列固件**提供微信读书安装与启动器支持；使用 3.27 或更早固件时，请参考微信读书官方提供的安装说明。

3.28.0.172 正式版的基础资源覆盖 Paper Pro、Paper Pro Move、Paper Pure、reMarkable 1 和 reMarkable 2。原生简体中文、拼音输入法和经典点击翻页覆盖五款设备；阅读增强、笔记增强、中文精确取词、彩色/黑白快刷及微信读书启动器仅覆盖 Paper Pro 与 Paper Pro Move。AppLoad 与 KOReader 尚未支持 3.28.0.172。

Windows x64 与 macOS ARM64 应用安装包从 GitHub Releases 提供；更新后的固件功能资源同步发布至 GitHub 与腾讯云 COS。微信读书官方安装包始终直接从官方 CDN 下载。

## English

- **Precise Chinese highlighting**: Reading Enhancements on Paper Pro and Paper Pro Move 3.28.0.172 can snap selections to Chinese character boundaries while preserving stock English word expansion and gestures.
- **Online WeRead installation**: On supported Paper Pro and Paper Pro Move 3.28 firmware, rmtool can download and repair RemarkableWeRead v1.0.0 directly from the official WeRead CDN. The official package is neither bundled nor mirrored by rmtool.
- **WeRead launcher**: A single device Settings entry offers normal, color-fast, and monochrome-fast launch modes, with independent periodic full-refresh intervals for the two fast modes.
- **Integrated reading refresh modes**: The global Reading Enhancements switch only authorizes the feature; each PDF/EPUB stores its own refresh mode.
- **Safer local plugin updates**: Managed shared-Xovi installations now carry a structured receipt. Real-device test revisions can be upgraded without adding a hard-coded fingerprint for every build, while paths, contents, permissions, and runtime identity remain strictly verified.

rmtool supports WeRead installation and its launcher only on **3.28 firmware**. For 3.27 and earlier firmware, follow the installation instructions provided by WeRead.

Stable 3.28.0.172 base resources cover Paper Pro, Paper Pro Move, Paper Pure, reMarkable 1, and reMarkable 2. Native Simplified Chinese, Pinyin Input, and classic Tap Page Turn cover all five devices. Reading Enhancements, Note Enhancements, precise Chinese highlighting, color/monochrome fast modes, and the WeRead launcher cover Paper Pro and Paper Pro Move only. AppLoad and KOReader are not yet supported on 3.28.0.172.

Windows x64 and macOS ARM64 application packages are available from GitHub Releases. Updated firmware feature resources are published to both GitHub and Tencent COS; the official WeRead package is always downloaded directly from its official CDN.
