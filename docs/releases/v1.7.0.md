# rmtool v1.7.0

## English

- Added fully offline Pinyin input for the system keyboard and physical
  keyboards, managed directly from rmtool.
- Added exact packages for Paper Pro and Paper Pro Move `3.27.1.0`, `3.27.3.0`,
  `3.28.0.162`, `3.28.0.163`, and `3.28.0.164`, plus Paper Pro `3.28.0.166`.
- The Chinese keyboard now appears as `中文` when the device UI uses Simplified
  Chinese.
- Pinyin input, native Simplified Chinese, tap-to-turn, and fast monochrome now
  share one rmtool-managed plugin runtime while retaining independent switches.
- Firmware resources are available from both Tencent COS and GitHub Releases
  with exact device, firmware, file-size, and SHA-256 verification.

Installation and removal do not restart the device automatically. Restart it
manually from the device menu after rmtool finishes and closes the SSH session.
Windows x64 and macOS ARM64 application downloads are published on GitHub
Releases.

## 中文

- 新增完全离线的拼音输入法，可用于系统软键盘和实体键盘，并直接由 rmtool
  安装、停用和管理。
- 精确支持 Paper Pro 与 Paper Pro Move 的 `3.27.1.0`、`3.27.3.0`、
  `3.28.0.162`、`3.28.0.163`、`3.28.0.164`，以及 Paper Pro
  `3.28.0.166`。
- 设备使用简体中文界面时，键盘语言会正确显示为“中文”。
- 拼音输入、原生简体中文、点击翻页和快速黑白共用一套 rmtool 插件运行时，
  同时保留各自独立的启停状态。
- 固件资源同时发布到腾讯云 COS 与 GitHub Releases，并严格校验设备、固件、
  文件大小和 SHA-256。

安装和停用不会自动重启设备。rmtool 完成操作并关闭 SSH 后，请从设备菜单
手动重启。Windows x64 与 macOS ARM64 应用安装包通过 GitHub Releases 发布。
