# rmtool v1.16.8

## 中文

- **增加 RM1/RM2 中文兜底字体：** 在老设备缺少内置 CJK 字体时，中文插件可使用随 rmtool 提供的常用简体中文字体，避免因系统没有中文字体而无法完成汉化。
- **区分系统字体与 EPUB 字体：** 系统字体仍会安装到设备系统字体位置并执行老设备空间检查；仅用于 EPUB 阅读的字体放在用户目录，不受系统字体 `/data` 空间限制影响。
- **加强老设备安全保护：** 上传前校验兜底字体资源，提示 RM1/RM2 存储空间有限，并在部署失败时回滚已修改的字体文件，避免留下半成品状态。

Windows x64 与 macOS ARM64 应用安装包从 GitHub Releases 提供。

## English

- **Added an RM1/RM2 CJK fallback font:** When a legacy device has no built-in CJK font, the Chinese localization plugin can use the bundled common Simplified Chinese font instead of failing because the system has no Chinese font.
- **Separated system fonts from EPUB fonts:** System fonts still go through device storage checks, while EPUB-only fonts stay in the user area and are not constrained by the system-font `/data` limit.
- **Improved legacy-device safeguards:** The fallback asset is validated before upload, RM1/RM2 storage warnings are shown before deployment, and failed deployments roll back modified font files.

Windows x64 and macOS ARM64 application packages are provided through GitHub Releases.
