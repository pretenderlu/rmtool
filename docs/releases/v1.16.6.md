# rmtool v1.16.6

## 中文

- **修复 RM1 系统字体设置：** 修正 `/data` 分区可用空间检测在部分设备上读取 `df` 表头 `Available` 的问题。
- **兼容表格化 `df` 输出：** 只接受明确的数字可用空间值；空值、异常文本和格式不完整的返回仍会安全终止，不会修改字体或系统配置。
- **保持原有保护：** 24 MiB 空间预留、字体替换、回滚和锁屏字体镜像逻辑均未改变。

Windows x64 与 macOS ARM64 应用安装包从 GitHub Releases 提供。

## English

- **Fixed RM1 system-font activation:** Corrected `/data` free-space detection on devices where the `df` header value `Available` was read instead of a numeric result.
- **Robust `df` parsing:** Only an unambiguous numeric free-space value is accepted; empty, malformed, or incomplete output still fails closed before changing the font or system configuration.
- **Existing protections preserved:** The 24 MiB reserve, font replacement, rollback, and lock-screen font mirror behavior are unchanged.

Windows x64 and macOS ARM64 application packages are provided through GitHub Releases.
