# rmtool v1.9.0

## English

- Redesigned Device Tools as a compact, searchable plugin browser. Select a
  tool to view its description and controls without scrolling through every
  feature.
- Added one-click status detection for all supported rmtool plugins and removed
  the obsolete traditional localization entry.
- Improved system-font switching for complete large Chinese fonts. rmtool now
  checks the space left after replacement, safely preserves the previous font,
  and no longer rejects fonts through a fixed size limit.

Windows x64 portable and single-file packages, plus the macOS ARM64 application,
are available from GitHub Releases.

## 中文

- 将设备工具重构为紧凑、可搜索的插件列表；选中工具后再查看说明和操作，
  无需在所有功能之间反复滚动。
- 增加一键检测全部已支持 rmtool 插件的状态，并移除过时的传统界面汉化
  入口。
- 优化完整大体积中文字体的系统字体切换：按替换后的剩余空间判断，安全
  保留原字体，不再使用固定字体大小限制。

Windows x64 便携版、Windows x64 单文件版和 macOS ARM64 应用可从 GitHub
Releases 下载。
