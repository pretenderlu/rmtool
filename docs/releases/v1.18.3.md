# rmtool v1.18.3

## 中文

- 修复系统字体安装时“挂载点忙”和回滚不完整的问题，新增字体设置修复入口。
- 修复插件安装时的意外断线和遗留锁，增加检测后确认重启恢复的入口。
- 修复扫码传输被未启用的旧插件文件阻止安装的问题。
- 修复 RM1/RM2 屏幕预览的兼容性问题。

## English

- Fix busy-mount and incomplete rollback errors during system-font installation, and add a font-settings repair action.
- Fix unintended disconnections and leftover locks during plugin installation, with a confirmed restart recovery action after detection.
- Fix QR transfer installation being blocked by inactive legacy plugin files.
- Fix screen-preview compatibility on RM1/RM2.
