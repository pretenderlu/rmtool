# rmtool v1.4.6

## English

> Improves localization package availability in mainland China with a Tencent
> COS mirror, while retaining independent fallbacks and the existing package
> integrity checks.

### Localization source fallback

- Localization catalogs now try the Tencent COS mainland mirror first, then
  the fixed GitHub `localization-assets` release.
- If both remote catalogs are unavailable or invalid, rmtool falls back to a
  previously validated local cache and finally the baseline manifest bundled
  with the application.
- Package payloads continue to use validated cache entries when available,
  then try COS and GitHub in order.
- Every downloaded `.qm` must match the manifest's exact byte size and
  SHA-256 before rmtool accepts it.

### Release packaging

- Windows and macOS packages include the baseline `manifest.json` so the
  package catalog remains available when both remote sources fail.
- Firmware-specific `.qm` files are not bundled with rmtool. Offline package
  installation still requires a matching package that was previously cached
  or loaded from a local file.

### Mirror synchronization

- A GitHub Actions workflow now synchronizes the fixed
  `localization-assets` release to Tencent COS after validating the release
  manifest and every referenced `.qm`.
- The workflow uploads all `.qm` payloads before publishing `manifest.json`,
  then verifies the resulting objects through the public COS endpoint.
- Tencent Cloud credentials used by the workflow require only the COS
  `PutObject` permission. The workflow does not delete or administer COS
  objects.

## 中文

> 通过腾讯云 COS 中国大陆镜像提升汉化包获取的可用性，同时保留独立回退路径和原有的严格完整性校验。

### 汉化资源回退

- 汉化目录现在优先尝试腾讯云 COS 中国大陆镜像，再尝试固定的 GitHub
  `localization-assets` Release。
- 两个远程目录均不可用或内容无效时，rmtool 会依次回退到此前验证通过的本地缓存和应用内置的基础清单。
- 汉化包文件会优先复用验证通过的缓存；需要联网下载时，依次尝试 COS 和 GitHub。
- 每个下载的 `.qm` 都必须与清单中记录的精确字节大小和 SHA-256 一致，rmtool 才会接受。

### 发布包内容

- Windows 和 macOS 发布包会内置基础 `manifest.json`，确保两个远程来源均不可用时仍可读取汉化包目录。
- 固件对应的 `.qm` 不会打包进 rmtool。离线安装仍需使用此前已缓存或由用户从本地加载的匹配汉化包。

### 镜像同步

- 新增 GitHub Actions 工作流，在校验固定 `localization-assets` Release 的清单和所有引用的 `.qm` 后，将资产同步至腾讯云 COS。
- 工作流始终先上传全部 `.qm`，最后发布 `manifest.json`，随后通过 COS 公开地址重新下载并校验。
- 工作流使用的腾讯云凭据只需要 COS `PutObject` 权限，不会删除或管理 COS 对象。
