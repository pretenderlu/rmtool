# rmtool v1.16.3

## 中文

- **插件卸载：** 原生简体中文、拼音输入法、阅读增强、笔记增强、点击翻页、快速刷新和微信读书启动入口现在都支持独立卸载，并保留仍在使用的共享 XOVI 运行时与其他插件。
- **AppLoad 生命周期：** AppLoad 现在明确区分“停用”和“卸载”；卸载 AppLoad 前会检查 KOReader 依赖，避免删除仍在使用的显示桥。
- **KOReader 卸载优化：** 卸载会真正删除程序主体，只保留设置、历史、截图等白名单用户数据；“彻底清理旧版残留”仍保持独立的不可逆清理流程。
- **安全保护：** 卸载未知、被修改、混合或正在运行的安装会被拒绝；原生中文卸载前会先把当前语言切回英文。所有卸载操作完成后都会关闭 SSH，并提示手动重启设备。
- **固件事务修复：** 固件更新结果文件缺失时，只有在设备已重启并完整匹配目标 A/B 分区、固件版本、平台、xochitl 指纹和健康状态后，才会核销事务，不再误报为未知状态。

本版本未新增固件功能资源包。Windows x64 与 macOS ARM64 应用安装包从 GitHub Releases 提供。

## English

- **Plugin uninstall:** Native Simplified Chinese, Pinyin Input, Reading Enhancements, Note Enhancements, Tap Page Turn, Fast Refresh, and the WeRead launcher now support independent uninstall actions while preserving shared XOVI runtime resources and other plugins.
- **AppLoad lifecycle:** AppLoad now clearly separates Disable from Uninstall; uninstall checks for KOReader dependencies before removing the display bridge.
- **KOReader uninstall:** Uninstall now removes the program tree and keeps only allowlisted user data such as settings, history, and screenshots. Permanently Remove Legacy Files remains a separate irreversible cleanup flow.
- **Safety checks:** Unknown, modified, mixed, or running installations are refused. Native Chinese switches the selected language back to English before uninstalling. Successful uninstall operations close SSH and prompt for a manual device restart.
- **Firmware transaction fix:** When a firmware result file is missing, rmtool reconciles the transaction only after the device has rebooted into an exact target A/B slot, firmware version, platform, xochitl fingerprint, and healthy state.

This release adds no new firmware payloads. Windows x64 and macOS ARM64 application packages are provided through GitHub Releases.
