# rmtool v1.15.5

## English

- Firmware updates restore compatible plugins more safely while preserving AppLoad and KOReader data when those apps are not yet supported.
- Firmware management now follows the device-first workflow: refresh device status, fetch official firmware, download, then install. Restart reminders appear after firmware installation and plugin restoration.
- Pinyin installations left by a firmware upgrade are now offered as repair/update instead of being reported as damaged.
- Reading Enhancements and Note Enhancements show only the package for the connected firmware.
- Fixed a false permission warning that could block legacy-plugin recovery, and removed duplicate warning text.

AppLoad and KOReader remain unavailable on firmware 3.28.0.172 pending upstream support.

Windows x64 and macOS ARM64 application packages are available only from GitHub Releases. Firmware feature packages are unchanged.

## 中文

- 固件更新后会更安全地恢复兼容插件；暂不兼容的 AppLoad 和 KOReader 会跳过恢复，同时保留应用数据。
- 固件管理按使用顺序排列：刷新设备状态、获取官方固件、下载、安装；安装固件和恢复插件后都会提示重启设备。
- 固件升级后遗留的拼音输入法现在会显示为可修复/更新，不再误报损坏。
- 阅读增强和笔记增强只显示当前连接固件对应的资源包。
- 修复可能阻止旧版插件恢复的权限误报，并去除重复提示。

AppLoad 和 KOReader 暂不支持固件 3.28.0.172，需等待上游适配。

Windows x64 与 macOS ARM64 应用安装包仅从 GitHub Releases 提供；固件功能资源包未变更。
