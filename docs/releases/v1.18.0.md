# rmtool v1.18.0

## 中文

- 新增扫码传书：Move 的 3.28.0.172 / 3.29.0.153 可在同一可信 Wi-Fi 下接收手机上传的 PDF、EPUB，单文件最多 200 MB，支持进度显示。
- 文档中心改用设备原生导入，自动准备服务并恢复原设置；USB 与 Wi-Fi 流程一致。自动传输组件覆盖五款设备的 3.28.0.172 / 3.29.0.153。
- 新增 Move 3.29.0.153 的汉化、拼音输入、阅读增强和笔记增强适配。
- 修复固件迁移未按提示跳过不兼容入口的问题，保留对应应用和数据。

扫码传书使用不加密的局域网 HTTP，仅在可信 Wi-Fi 下使用。首次安装传输组件后需手动重启一次。新增适配的实机验证范围见 [兼容性说明](https://github.com/pretenderlu/rmtool/blob/main/docs/device-firmware-support.md)。

## English

- Add QR book transfer for Move on 3.28.0.172 / 3.29.0.153: receive PDF/EPUB files from a phone on trusted Wi-Fi, with progress and a 200 MB per-file limit.
- Use the system-native importer in the document center, automatically preparing the service and restoring its setting over USB or Wi-Fi. The control component supports all five models on 3.28.0.172 / 3.29.0.153.
- Add Move 3.29.0.153 localization, Pinyin, reading and note enhancement packages.
- Fix firmware migration failing to skip incompatible launcher entries while preserving their apps and data.

QR transfer uses unencrypted local HTTP and requires trusted Wi-Fi. Reboot manually once after installing a transfer component. See the [compatibility notes](https://github.com/pretenderlu/rmtool/blob/main/docs/device-firmware-support.md) for hardware-verification coverage.
