# rmtool v1.16.14

## 中文

- **修复 RM1 插件安装空间问题：** RM1 的 3.28.0.172 共享插件改为存储在容量更大的 `/home` 分区，避免继续占用小容量根分区。已验证的旧安装可迁移，安装前仍检查空间并保留恢复保护。
- **修复 RM1/RM2 汉化资源路径：** 简体中文扩展使用对应的插件运行目录读取翻译资源，相关在线汉化包同步更新，并保留已发布旧包的检测与修复支持。
- **明确 Xovi 冲突原因：** 提示显示实际命中的文件或启动配置路径，不再把文件残留等同于已安装 Vellum 或正在运行的插件；不会自动删除来源不明的第三方文件。
- **完善诊断与错误提示：** 诊断日志补充冲突文件类型、链接目标、启动配置和实际加载信息；EPUB 字体操作失败时显示具体原因，便于定位问题。

RM1 的新存储方案已完成官方固件离线核对及自动化测试，仍待实机安装、重启和迁移验证。若根分区已经完全占满，仍需先安全处理已确认的残留，软件不会跳过空间或所有权校验。RM2、其他机型及较早 RM1 固件的插件部署路径不变，字体的密码锁屏选项不变。本次不新增设备或固件适配，也不包含尚待复现的 reManager mod 键盘冲突修复。

Windows x64 与 macOS ARM64 安装包见下方附件。RM1/RM2 的 3.28.0.172 汉化资源通过 GitHub 与腾讯云 COS 在线提供，不会打包进应用。

## English

- **Fixed RM1 plugin storage:** Shared plugins on RM1 3.28.0.172 now use the larger `/home` filesystem instead of consuming the small root filesystem. Verified existing installations can migrate, with space checks and recovery safeguards retained.
- **Fixed RM1/RM2 Chinese catalog paths:** The Chinese translator reads resources from the appropriate plugin runtime directory. Updated online packages retain detection and repair support for published predecessors.
- **Clearer Xovi conflict messages:** Detection identifies the actual conflicting files or startup configuration, without treating leftover files as proof of Vellum installation or a running plugin. Unknown third-party files are never deleted automatically.
- **Better diagnostics and errors:** Diagnostic bundles include conflict file types, link targets, startup configuration, and loaded-library evidence. EPUB font failures preserve the underlying error details.

The new RM1 storage layout has passed official-firmware offline checks and automated tests; real-device installation, reboot, and migration validation remain pending. A completely full root filesystem still requires safe cleanup of confirmed residue. Space and ownership checks are not bypassed. Plugin deployment paths on RM2, other models, and older RM1 firmware are unchanged, as is the font passcode-lock option. This patch adds no device or firmware ports and does not claim to fix the reManager mod keyboard conflict that still needs reproduction details.

Windows x64 and macOS ARM64 downloads are available below. Updated RM1/RM2 Chinese resources for 3.28.0.172 are downloaded from GitHub or Tencent COS, not bundled in the app.
