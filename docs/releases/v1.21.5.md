# rmtool v1.21.5

## 中文

- 修复阅读增强和微信读书入口对已验证旧包的误判，单独更新其中一项时保留其他插件。
- 连接设备后首次进入设备工具可检测全部插件，清楚区分可更新、可迁移和异常等状态。

## English

- Fix incorrect detection of verified older packages for reading enhancements and the WeRead launcher. Updating either one leaves other plugins unchanged.
- Scan all plugins when you first open Device Tools after connecting, and see which have updates, which can be migrated, and which have issues.
