# rmtool v1.14.2

## English

- On supported 3.28 firmware, EPUB reading now supports up to three custom
  font entries. Fonts are added in order automatically and can display their
  Chinese names in the reader's font menu, with no manual ordering required.
- Adding and removing EPUB fonts is safer: duplicate assignments are refused,
  removing an entry automatically closes the gap, and interrupted changes are
  rolled back without disturbing the existing font order.
- Improved Reading Enhancements updates and recovery. Supported existing
  installations are detected more reliably and can be updated or repaired
  while preserving the user's other reading settings and plugins.

The Windows x64 portable ZIP, Windows x64 single-file EXE, and macOS ARM64 app
ZIP are available from GitHub Releases.

## 中文

- 在受支持的 3.28 固件上，EPUB 阅读现支持最多三个自定义字体条目。字体会
  按添加顺序自动排列，并可在阅读器字体菜单中显示中文名称，无需用户手动
  选择槽位。
- EPUB 字体的添加与移除更加安全：拒绝重复设置，移除后自动前移补位，操作
  中断时会回滚且不会打乱原有字体顺序。
- 改进阅读增强的更新与恢复流程。软件可更可靠地识别受支持的已有安装，并在
  保留其他阅读设置和插件的情况下完成更新或修复。

Windows x64 便携版 ZIP、Windows x64 单文件 EXE 和 macOS ARM64 应用 ZIP
可从 GitHub Releases 下载。
