# rmtool v1.16.11

## 中文

- **修复 3.28.0.172 汉化清单漏项：** 补齐 Paper Pro、Paper Pro Move、Paper Pure、reMarkable 1 和 reMarkable 2 的官方原始法语载体指纹。RM1/RM2 升级到 3.28.0.172 后，原生简体中文插件不再因缺少精确清单而被错误阻止。
- **修复老设备兜底字体模式：** 不使用锁屏字体镜像时，明确保持字体安装在用户目录，不再意外按锁屏方案处理 `/data` 空间限制。
- **新增构建前矩阵门禁：** Windows 与 macOS 构建前都会校验各插件的设备、架构、固件版本、xochitl 指纹和汉化载体是否完整匹配，漏项会直接阻止构建。

Windows x64 与 macOS ARM64 应用安装包从 GitHub Releases 提供。

## English

- **Fixed the 3.28.0.172 localization manifest gap:** Added the exact official French carrier fingerprints for Paper Pro, Paper Pro Move, Paper Pure, reMarkable 1, and reMarkable 2. Native Simplified Chinese installation is no longer incorrectly blocked on RM1/RM2 after upgrading to 3.28.0.172.
- **Fixed the legacy-device fallback-font mode:** When lock-screen font mirroring is disabled, the fallback font remains explicitly managed in the user directory instead of accidentally applying the `/data`-limited lock-screen path.
- **Added a pre-build matrix gate:** Windows and macOS builds now validate that every plugin's device, architecture, firmware version, xochitl fingerprint, and localization carrier are covered. Missing entries stop the build immediately.

Windows x64 and macOS ARM64 application packages are provided through GitHub Releases.
