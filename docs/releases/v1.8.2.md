# rmtool v1.8.2

## English

- Fixed a shared Xovi state error caused by an empty feature directory left
  after disabling Native Chinese or another rmtool feature.
- Future feature removal now cleans obsolete directories while continuing to
  reject unknown or modified files.

Windows x64 portable and single-file packages, plus the macOS ARM64 application,
are available from GitHub Releases.

## 中文

- 修复停用原生中文或其他 rmtool 功能后，遗留空目录导致共享 Xovi 状态异常的
  问题。
- 后续停用功能会同步清理废弃目录，同时继续拦截未知或被修改的文件。

Windows x64 便携版、Windows x64 单文件版和 macOS ARM64 应用可从 GitHub
Releases 下载。
