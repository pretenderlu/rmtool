# rmtool v1.10.0

## English

- Added offline-verified support for Paper Pro Move beta firmware `3.28.0.166`
  (internal version `20260806095513`) across all five firmware packages:
  French-slot localization, the independent Simplified Chinese plugin, offline
  Pinyin input, tap-to-turn pages, and fast monochrome reading.
- Every new package is gated on the official 3.28.0.166 firmware image and the
  exact stock catalog and xochitl SHA-256 hashes, so nothing is inferred from
  version strings. Real-device validation on Paper Pro Move is still pending;
  the new targets remain labelled offline verified.

Windows x64 portable and single-file packages, plus the macOS ARM64 application,
are available from GitHub Releases.
