# rmtool v1.16.5

## 中文

- **修复设备维护误报：** 兼容 reMarkable 3.28 系列固件正常的 `/etc` overlay 挂载，不再因此错误阻止共享插件恢复检测。
- **保留安全校验：** 只有明确识别为系统标准 `/etc` overlay 时才放行；未知挂载、外部插件、符号链接、权限异常和无法确认归属的文件仍会被阻止。
- **显示应用版本：** 左侧底部显示当前 rmtool 版本号。
- **更新提醒：** 启动后后台检查 GitHub 最新正式 Release；发现新版本时显示可点击红点，点击可直达 GitHub Releases。离线或检查失败不会影响设备连接。

Windows x64 与 macOS ARM64 应用安装包从 GitHub Releases 提供。

## English

- **Fixed device-maintenance false positives:** Normal `/etc` overlay mounts on reMarkable 3.28 firmware no longer incorrectly block shared-plugin recovery inspection.
- **Safety checks remain strict:** Only the recognized stock `/etc` overlay is allowed; unknown mounts, external plugins, symlinks, unsafe permissions, and unverified ownership remain blocked.
- **Application version:** The current rmtool version is shown in the lower-left sidebar.
- **Update reminder:** A background check looks for the latest public GitHub Release. A newer release shows a clickable red dot that opens GitHub Releases; offline or failed checks never block device connections.

Windows x64 and macOS ARM64 application packages are provided through GitHub Releases.
