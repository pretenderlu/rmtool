# rmtool v1.15.9

## 中文

- 修复 macOS 应用无法验证 HTTPS 证书、导致在线清单与资源下载失败的问题。
- 恢复原生简体中文、拼音输入法、阅读增强、笔记增强、AppLoad 与官方固件管理等在线功能。

Windows x64 与 macOS ARM64 应用安装包从 GitHub Releases 提供。固件功能资源继续由 GitHub 与腾讯云 COS 双源分发。

## English

- Fixed HTTPS certificate validation in the macOS app, which prevented online manifests and resources from downloading.
- Restored online access for Chinese localization, Pinyin input, reading and note enhancements, AppLoad, and firmware management.

Windows x64 and macOS ARM64 application packages are available from GitHub Releases. Firmware feature resources continue to use GitHub and Tencent COS mirrors.
