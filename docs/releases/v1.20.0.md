# rmtool v1.20.0

## 中文

- 为 Paper Pro 和 Paper Pro Move 的 3.29.1.0 正式版提供现有插件精确适配，支持全新安装和从 .172/.153 固件升级迁移。
- 新增该版本的原生文档传输、扫码传输和微信读书入口；微信读书同时覆盖 3.29.0.152/.153，Move 的 3.29.1.0 迁移与入口已通过用户验收。
- AppLoad 升级至 v0.6.0，可在更新时联合迁移可验证的旧共享插件，并修复 KOReader 文件存在但启动入口缺失的问题。
- 新固件包均完成完整 QML 回放、ABI 和确定性构建检查；其他设备及功能仍需分别验收。

## English

- Add exact plugin support for Paper Pro and Paper Pro Move on stable 3.29.1.0, covering clean installation and migration from .172/.153.
- Add native document transfer, QR reception, and the WeRead launcher for this release; WeRead also covers 3.29.0.152/.153, and the user confirmed migration and the launcher on Move 3.29.1.0.
- Upgrade AppLoad to v0.6.0 with joint migration of verified legacy shared plugins, and repair missing KOReader launcher entries without deleting application data.
- Validate all new packages with full QML replay, ABI checks, and deterministic rebuilds; other devices and features still require individual hardware acceptance.
