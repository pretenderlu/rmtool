# rmtool v1.13.0

## English

- Restored plugin management for Paper Pure, reMarkable 1, and reMarkable 2:
  the toolbox again shows a **Tap to turn** entry for these devices (it
  appears only when the connected device has an exact tap package and no
  reading-enhancements package), with install, disable, firmware-residue
  cleanup, Vellum guidance, and local package loading. Every target on these
  devices is offline verified only and has not been deployed to a real
  device; the UI states this explicitly before every install.
- Package downloads now try the GitHub release first and automatically fall
  back to the Tencent COS mirror, so mainland users keep a working route
  when GitHub is unreachable. When both mirrors fail, the error dialog lists
  the exact GitHub and COS download URLs, can copy them to the clipboard,
  and can load a manually downloaded archive after the same size and
  SHA-256 verification, then retries the install automatically. This path
  never touches the device before the download succeeds, so the SSH session
  stays open.
- Added a one-click **diagnostic bundle export** (Device Tools > Diagnostics
  log export): it collects the local rmtool log tail plus a fixed whitelist
  of read-only device diagnostics (identity, xochitl service state, rmtool
  Xovi startup journal, shared-tree listings, drop-in, IME sidecar logs,
  disk and memory), previews every entry before saving, lets the user
  deselect the document-name-sensitive xochitl journal, and writes a small
  zip with a manifest of what was collected. Device credentials can never
  enter a bundle.

Windows x64 portable and single-file packages, plus the macOS ARM64 application,
are available from GitHub Releases.

## 中文

- 恢复 Paper Pure、reMarkable 1 和 reMarkable 2 的插件管理：工具箱重新为
  这些设备提供**点击翻页**入口（仅当连接设备有精确点击翻页包且没有
  阅读增强包时出现），支持安装、停用、固件残留清理、Vellum 卸载引导
  和本地资源包加载。这些设备上的全部目标仅有离线验证、尚未实机部署，
  界面会在每次安装前明确说明。
- 资源包下载默认优先访问 GitHub Release，失败后自动回退腾讯云 COS
  镜像，中国大陆用户在 GitHub 下载不畅时仍有可用路线。两个镜像都失败
  时，报错弹窗会列出 GitHub 与腾讯云 COS 的实际下载地址（可一键复制），
  并可导入手动下载的文件——同样通过大小与 SHA-256 校验——然后自动重试
  安装。下载成功前不会改动设备，SSH 会话保持打开。
- 新增一键**诊断日志导出**（设备工具 > 诊断日志导出）：采集 rmtool 本机
  日志末段和一组固定白名单的只读设备诊断信息（身份与版本、xochitl
  服务状态、rmtool Xovi 启动日志、共享目录清单、drop-in、拼音 sidecar
  日志、磁盘内存），保存前逐项预览，可单独取消可能包含文档名的
  xochitl 运行日志，最终生成带采集清单的小体积 zip。设备凭据在机制上
  不可能进入诊断包。

Windows x64 便携版、Windows x64 单文件版和 macOS ARM64 应用可从 GitHub
Releases 下载。
