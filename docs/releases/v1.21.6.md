# rmtool v1.21.6

## 中文

- 全面检测显示原生文档传输状态，可直接前往文档中心。
- 共享恢复受阻时，若已确认只需单独更新原生传输，提示更新入口，无需卸载其他插件。

## English

- The plugin scan shows native document transfer status and links directly to Documents.
- If shared recovery is blocked and only a verified native transfer update is needed, rmtool points to that update without asking users to uninstall other plugins.
