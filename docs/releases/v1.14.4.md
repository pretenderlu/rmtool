# rmtool v1.14.4

## English

- **Direct table-of-contents access:** Supported PDF and EPUB reading menus now include a direct entry to reMarkable's native Table of Contents screen.
- **The system remains the source of truth:** reMarkable already provides the TOC data, hierarchy, navigation, and screen. rmtool does not parse or generate a separate TOC; it only exposes the existing screen outside the deeper stock menu.
- **Current firmware coverage:** Reading Enhancements revision 7 covers all 14 supported Paper Pro and Paper Pro Move stable/beta firmware targets, with safe in-place updates from trusted revision 6 installations.
- **Device verified:** The new entry has passed real-device reading and navigation tests.

Packaged Windows x64 and macOS ARM64 apps are available from GitHub Releases. Firmware resources are distributed through both the fixed GitHub asset release and the Tencent COS mirror.

## 中文

- **目录直达入口：** 受支持的 PDF 和 EPUB 阅读菜单现在可以直接打开 reMarkable 系统原生目录页。
- **目录仍由系统提供：** reMarkable 本身已经提供目录数据、层级、跳转和原生页面。rmtool 不重新解析或生成目录，只把原本位于更深层级菜单中的系统目录入口提到外面。
- **当前固件覆盖：** 阅读增强 revision 7 覆盖 Paper Pro 和 Paper Pro Move 当前支持的全部 14 个正式版、测试版固件目标，并可从可信的 revision 6 安装原地安全更新。
- **已完成实机验证：** 目录入口及跳转已通过实机阅读测试。

Windows x64 与 macOS ARM64 应用安装包可从 GitHub Releases 下载；固件资源同时发布到固定 GitHub 资源 Release 与腾讯云 COS 镜像。
