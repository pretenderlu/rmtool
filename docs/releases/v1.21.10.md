# rmtool v1.21.10

## 中文

- 适配 reMarkable 2 正式固件 3.29.2.1：简体中文、拼音输入、点击翻页、原生文档上传及扫码传书。
- 该固件新增自定义系统字体的空间修复：先备份到 `/home`，验证新配置后才清理旧副本。本版仅识别已收录的字体文件。

## English

- Adds support for Simplified Chinese, Pinyin, tap-to-turn, native document upload and QR transfers on reMarkable 2 firmware 3.29.2.1.
- Adds space recovery for custom system fonts on this firmware. This version recognizes only known font files; it backs them up to `/home` and verifies the new configuration before removing the old copy.
