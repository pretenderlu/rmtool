# rmtool v1.21.1

## 中文

- KOReader 重装、修复和卸载会保留官方程序以外的全部用户数据，包括阅读进度、标注、词典、自装插件和补丁；卸载后再次安装会自动恢复。
- 固件操作在写入分区前停止时会自动解除锁定；写入失败或结果不明时，可在固件页刷新后使用“解除固件锁定”，解除前会确认设备没有待应用更新、启动分区未切换且错误计数为 0。
- 恢复页检查残缺插件的速度大幅提升，不再需要等待数十秒。
- 修复 rmkit-cn 汉化启用和还原后不显示结果、已装拼音时更新 AppLoad 报错，以及还原汉化会删除原生中文兜底字体的问题。
- reMarkable 1 在 3.29.0.153 和 3.29.1.0 上的残留清理、迁移和 AppLoad 链接恢复正常。
- 断线时会提示操作结果未知，界面异常不再导致程序退出；有设备操作时关闭窗口会先确认。
- Windows 版构建后会自动做联网自检，依赖版本按哈希锁定。

## English

- KOReader reinstall, repair, and uninstall keep every file that is not part of the official release, including reading progress, highlights, dictionaries, user plugins, and patches; the next install restores them after an uninstall.
- A firmware job that stops before writing is unlocked automatically. After a failed or uncertain job, **Release firmware lock** is available once the device is refreshed; it first confirms there is no pending update, the next-boot partition is unchanged, and the A/B error counters are zero.
- Checking incomplete plugin residue on the recovery page is now much faster.
- Fix rmkit-cn localization not showing a result after enabling or restoring, AppLoad updates failing when Pinyin is installed, and restore removing the native Chinese fallback font.
- Residue cleanup, migration, and AppLoad links work again on reMarkable 1 with 3.29.0.153 and 3.29.1.0.
- A dropped connection now reports that the result is unknown, interface errors no longer close the app, and closing the window during a device operation asks first.
- Windows builds run an online self-check after packaging, and build dependencies are hash-locked.
