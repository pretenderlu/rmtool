# rmtool v1.16.10

## 中文

- **修复拼音输入法升级后无法修复：** 针对固件升级或共享插件清理后仍保留 rmtool 拼音服务文件、但共享 Xovi 入口缺失的设备，检测结果现在会提供“修复并更新”，重新接入当前固件对应的共享入口。
- **保留安全校验：** 只有外部拼音服务文件逐项匹配 rmtool 受信清单时才允许自动修复；无法验证来源的残留仍会阻断操作，不会被强行覆盖。

Windows x64 与 macOS ARM64 应用安装包从 GitHub Releases 提供。

## English

- **Fixed Pinyin recovery after firmware upgrades:** Devices that retain rmtool's Pinyin service files after a firmware upgrade or shared-plugin cleanup, but lose the shared Xovi entry, now receive a **Repair and update** action that reconnects the service to the current firmware's shared entry point.
- **Safety checks preserved:** Automatic repair is enabled only when every external Pinyin service file matches the rmtool trusted manifest. Unverified residue remains blocked and is never force-overwritten.

Windows x64 and macOS ARM64 application packages are provided through GitHub Releases.
