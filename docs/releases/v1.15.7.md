# rmtool v1.15.7

## 中文

- 五款受支持设备均新增独立的“屏幕预览”页面，可在电脑上动态查看当前设备画面。
- 提供独立的开启与停止按钮，并支持手动刷新和 PNG 另存为。
- 屏幕预览不会在设备资料库中创建 PDF，离开页面或断开设备时会自动停止。

Paper Pro Move 已完成实机验证，其余机型使用对应显示栈并在运行时校验读取条件。固件功能资源包没有变化。

Windows x64 与 macOS ARM64 应用安装包从 GitHub Releases 提供。

## English

- All five supported devices now have a dedicated Screen Preview page for viewing the current device screen on a computer.
- Preview has separate start and stop controls, manual refresh, and PNG Save As.
- Screen Preview creates no PDF in the device library and stops automatically when leaving the page or disconnecting the device.

Paper Pro Move is live-device verified; the other models use their corresponding display stack with runtime capability checks. Firmware feature packages are unchanged.

Windows x64 and macOS ARM64 application packages are available from GitHub Releases.
