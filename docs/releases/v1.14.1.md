# rmtool v1.14.1

## English

- Fixed the reading-enhancements settings page so conditional controls now
  show a disabled state: selecting **By chapter** cleanup grays out the
  fixed-page-interval panel, and turning off the master switch grays out all
  four feature panels. Previously these panels kept full opacity while their
  inputs were inert. The graying follows the stock system-settings pattern
  (`opacity 0.5` when disabled).
- Reading-enhancements package revision 4 rebuilds all fourteen firmware
  targets with the disabled-state styling. Existing revision-3 installations
  are recognized exactly and update in place through the verified repair
  path; per-book settings, other rmtool plugins, and the shared runtime are
  preserved.
- Verified on real devices: Paper Pro at `3.28.0.169` beta and Paper Pro Move
  at `3.27.3.0` stable, including the repair update flow and the graying
  behavior after restart.

Windows x64 portable and single-file packages, plus the macOS ARM64 application,
are available from GitHub Releases.

## 中文

- 修复阅读增强设置页的禁用状态显示：选择**按章节**清残影时，“固定页数
  间隔”面板会灰显；关闭总开关时，四个功能面板同时灰显。此前这些面板在
  不可用时仍保持完全不透明，看不出无法设置。灰显样式与系统原生设置页
  一致（禁用时 0.5 透明度）。
- 阅读增强包修订 4 重建全部 14 个固件目标。已安装的修订 3 会被精确识别，
  并通过验证修复路径原地更新；单书设置、其他 rmtool 插件和共享运行时
  全部保留。
- 已完成双机实机验证：Paper Pro（`3.28.0.169` 测试版）与 Paper Pro Move
  （`3.27.3.0` 正式版），覆盖修复更新流程与重启后的灰显行为。

Windows x64 便携版、Windows x64 单文件版和 macOS ARM64 应用可从 GitHub
Releases 下载。
