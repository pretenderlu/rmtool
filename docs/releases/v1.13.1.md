# rmtool v1.13.1

## English

- Fixed the diagnostic bundle export on real devices: the reMarkable BusyBox
  `head` has no `-c` option, so every capped device collection command failed
  and the v1.13.0 bundle only contained the PC-side entries. Capping now uses
  BusyBox-safe `tail -c`, which also keeps the most recent log lines when
  output exceeds the cap. Verified on a Paper Pro at `3.28.0.169`: all
  thirteen items collect, the platform label resolves correctly, and a bundle
  builds from real device output.

Windows x64 portable and single-file packages, plus the macOS ARM64 application,
are available from GitHub Releases.

## 中文

- 修复诊断日志导出在真机上无法采集的问题：reMarkable 的 BusyBox `head`
  不支持 `-c` 参数，导致所有带限额的设备采集命令全部失败，v1.13.0 的
  诊断包只剩 PC 侧内容。现改用 BusyBox 兼容的 `tail -c` 限额，输出超限时
  保留的也是最靠近末尾的最新日志。已在 `3.28.0.169` 的 Paper Pro 上实测：
  13 项全部采集成功、平台代号解析正确、诊断包正常生成。

Windows x64 便携版、Windows x64 单文件版和 macOS ARM64 应用可从 GitHub
Releases 下载。
