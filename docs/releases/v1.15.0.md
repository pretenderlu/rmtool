# rmtool v1.15.0

## English

- **New Note Enhancements plugin:** Paper Pro and Paper Pro Move can reduce repeated color-settlement flashes while handwriting. Set a global default, then override each notebook with a 5/10/30-second pen-up delay or page-turn-only refresh.
- **Stock behavior remains one switch away:** Turning Note Enhancements off restores the original approximately one-second pen-up refresh. Reading Enhancements and every other verified rmtool plugin remain independent.
- **Safer upgrades:** Published Reading Enhancements revisions are detected precisely, and Pinyin installations that survive a firmware update with identical verified files can now be repaired instead of being reported as damaged.
- **Current firmware coverage:** Note Enhancements covers all 14 supported Paper Pro and Paper Pro Move 3.27 stable and 3.28 beta targets. Move 3.27.3 has passed real-device installation, reboot, global/per-notebook settings, and refresh-policy tests; the remaining targets are verified offline against official firmware.

Windows x64 and macOS ARM64 application packages are available from GitHub Releases. Firmware resources are distributed through both fixed GitHub asset Releases and the Tencent COS mirror.

## 中文

- **新增笔记增强：** Paper Pro 与 Paper Pro Move 可减少彩色手写时频繁出现的沉淀刷新。设备设置保存全局默认，每本笔记还可单独选择提笔后等待 5、10、30 秒刷新，或仅在翻页时刷新。
- **随时恢复原生行为：** 关闭笔记增强后恢复系统原生约 1 秒的提笔刷新；阅读增强及其他已验证插件仍可独立使用。
- **升级更稳妥：** 阅读增强只识别真正公开发布过的旧版本；固件升级后，若拼音输入法文件完整且与当前包完全一致，rmtool 会提供安全修复更新，不再误报为损坏。
- **当前固件覆盖：** 笔记增强覆盖 Paper Pro 与 Paper Pro Move 当前支持的全部 14 个 3.27 正式版、3.28 测试版固件目标。Move 3.27.3 已完成安装、重启、全局与单笔记设置、刷新策略切换实机验证，其余目标完成官方固件离线验证。

Windows x64 与 macOS ARM64 应用安装包可从 GitHub Releases 下载；固件资源同时发布到固定 GitHub 资源 Release 与腾讯云 COS 镜像。
