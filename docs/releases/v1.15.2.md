# rmtool v1.15.2

## English

- **KOReader first-install fix:** Fixed an issue that could prevent KOReader from installing through rmtool for the first time on new or cleaned devices. Affected users can retry the installation directly with this release.

Windows x64 and macOS ARM64 application packages are available from GitHub Releases. No firmware feature resource packages changed in this release.

## 中文

- **修复 KOReader 首次安装问题：** 修复了全新或已清理设备首次通过 rmtool 安装 KOReader 时可能失败的问题，受影响的用户使用此版本后可直接重试安装。

Windows x64 与 macOS ARM64 应用安装包可从 GitHub Releases 下载；本次没有更新固件功能资源包。
