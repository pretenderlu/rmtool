# rmtool v1.4.7

## English

> Keeps custom Chinese UI fonts available on the passcode screen before an
> encrypted `/home` filesystem is unlocked.

### Boot-time UI font mirror

- Applying a system UI font now creates one byte-identical mirror under an
  rmtool-owned path in `/usr/share/fonts/ttf/rmtool`.
- An rmtool-owned system Fontconfig rule makes that mirror available before
  the user font directory under encrypted `/home` can be mounted.
- Font bytes, available root space, cache refresh, and system-only Fontconfig
  matches are verified before the operation succeeds.
- Font and configuration replacement is transactional. Failures restore the
  exact previous user Fontconfig, system font, and system Fontconfig bytes.
- Localization restore distinguishes localization-owned mirrors from fonts
  later selected by the user and preserves the latter.

### Font manager

- The active font can now be selected again with **Reapply System Font**.
  This lets existing installations with only one uploaded font create or
  repair the new boot-time mirror.
- Inactive fonts continue to use **Set as System Font**; the active font still
  cannot be deleted.
- Device restart remains a separate confirmed action. Font installation and
  repair never restart xochitl or reboot the device automatically.

### Validation

- Verified on a physical device with an encrypted home and passcode enabled.
- The passcode screen and the normal UI both render Chinese with the selected
  custom font after a cold boot.

## 中文

> 让自定义中文界面字体在加密 `/home` 解锁前的密码界面中也能正常使用。

### 启动阶段字体镜像

- 应用系统界面字体时，会在 `/usr/share/fonts/ttf/rmtool` 的 rmtool 专用路径中建立一份字节完全一致的镜像。
- 新增 rmtool 专用系统 Fontconfig 规则，使加密 `/home` 下的用户字体目录尚未挂载时也能读取该镜像。
- 操作完成前会校验字体字节、根分区可用空间、字体缓存，以及不依赖 `/home` 的系统 Fontconfig 匹配结果。
- 字体和配置替换采用事务式处理；失败时会恢复此前用户 Fontconfig、系统字体和系统 Fontconfig 的精确原始字节。
- 汉化还原会区分汉化流程建立的镜像与用户后来主动选择的字体，不会误删后者。

### 字体管理

- 当前字体现在可以通过 **重新应用系统字体** 再次执行设置，只有一个已上传字体的旧安装也能补建或修复启动阶段镜像。
- 未启用字体仍显示 **设为系统字体**，当前字体仍禁止删除。
- 设备重启继续作为独立确认操作；字体安装和修复不会自动重启 xochitl 或设备。

### 验证情况

- 已在启用锁屏密码和加密用户分区的真机上完成验证。
- 冷启动后，密码解锁界面和正常系统界面均可使用所选自定义字体正确显示中文。
