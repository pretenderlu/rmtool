# rmtool v1.5.1

## English

- Adds Chinese localization, tap-to-turn, and fast monochrome packages for
  Paper Pro and Paper Pro Move beta firmware 3.28.0.164.
- Safely detects and removes verified rmtool plugin residue left after a
  firmware upgrade, so current-firmware plugins can be installed again.
- Keeps exact hardware, firmware, and file-hash checks before every install or
  cleanup operation.

Firmware resources are available from Tencent COS with GitHub fallback. The
Windows x64 and macOS ARM64 application downloads remain on GitHub Releases.

## 中文

- 新增 Paper Pro 与 Paper Pro Move 测试固件 3.28.0.164 的汉化、点击翻页和快速黑白资源。
- 固件升级后可安全识别并清理经过验证的 rmtool 插件残留，随后可重新安装当前固件补丁。
- 安装和清理前继续严格校验硬件、固件及文件哈希。

固件资源优先从腾讯云 COS 下载，并以 GitHub 作为备用源；Windows x64 与 macOS ARM64
应用安装包仍仅通过 GitHub Releases 发布。
