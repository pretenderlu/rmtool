# rmtool v1.15.8

## 中文

- 字体管理现在会在添加 EPUB 阅读字体时自动准备所需的菜单支持，无需预先安装或开启阅读增强功能。
- EPUB 字体名称过长时会自动省略显示，不再越过阅读器菜单边界；完整字体名称与选择结果保持不变。
- 安装、迁移和更新过程继续使用固件精确匹配与完整性验证，操作完成后按提示重启设备即可生效。

Windows x64 与 macOS ARM64 应用安装包从 GitHub Releases 提供。更新后的阅读增强资源同步发布至 GitHub 与腾讯云 COS。

## English

- Font Manager now prepares the required EPUB font-menu support automatically, without requiring users to install or enable reading features first.
- Long custom font names are elided within the reader menu while preserving the full font identity and selection behavior.
- Installation, migration, and updates continue to use exact firmware matching and integrity verification. Restart the device when prompted to apply the change.

Windows x64 and macOS ARM64 application packages are available from GitHub Releases. Updated Reading Enhancements resources are published to both GitHub and Tencent COS.
