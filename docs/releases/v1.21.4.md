# rmtool v1.21.4

## 中文

- 改善插件安装、迁移和中断恢复，保留外部插件及 KOReader 数据。
- 加强字体、汉化和固件操作的备份、回滚与异常保护。
- 修复点击翻页触控处理，改善拼音候选更新和输入保留。
- 修正文档导出的空白页、笔迹位置和荧光笔显示，避免导出失败覆盖已有文件。
- 改善连接异常提示、任务进度和图片处理，减少界面卡顿。

## English

- Improve plugin installation, migration and recovery after interruptions while preserving external plugins and KOReader data.
- Strengthen backups, rollback and failure protection for fonts, localization and firmware operations.
- Fix tap-to-turn touch handling and improve Pinyin candidate updates and retention of typed text.
- Fix blank pages, stroke positioning and highlighter rendering in document exports; preserve existing files when export fails.
- Improve connection error reporting, task progress and image handling for a more responsive interface.
