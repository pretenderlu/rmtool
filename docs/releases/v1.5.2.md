# rmtool v1.5.2

## English

- The periodic full-refresh control for Fast Monochrome Reading now appears
  only in PDF and EPUB readers while the feature is enabled.
- Notebook pages no longer count toward or trigger the reading cleanup cycle.
  Existing Fast Monochrome Reading installations can be updated safely through
  rmtool.

Feature resources are available from Tencent COS with GitHub fallback. Windows
x64 and macOS ARM64 application downloads remain on GitHub Releases.

## 中文

- 快速黑白阅读的周期完整刷新选项，现在只会在已开启该功能的 PDF 和
  EPUB 阅读界面中显示。
- 笔记页面不再累计翻页次数或触发阅读刷新；已有的快速黑白阅读插件可通过
  rmtool 安全更新。

功能资源优先从腾讯云 COS 下载，并以 GitHub 作为备用源；Windows x64 与
macOS ARM64 应用安装包仍仅通过 GitHub Releases 发布。
