# rmtool v1.4.5

## English

> Adds verified manual localization package fallbacks while keeping automatic
> installation as the default, and makes the package list focus on the exact
> firmware running on the connected device.

### Localization package fallback

- "Enable Chinese" remains the primary workflow: rmtool automatically
  downloads, verifies, and installs the exact package matched to the connected
  device.
- After a successful status check, "Get Localization Package" can save the
  matched `.qm` file to the computer or copy its direct download URL for
  unreliable network conditions.
- "Load Local Localization Package" imports a previously downloaded file into
  rmtool's existing cache. The file must match the current device package's
  exact byte size and SHA-256 before it is accepted.
- Importing a local package never writes to the device. The existing guarded
  "Enable Chinese" flow still performs firmware, stock carrier, font, backup,
  deployment, and post-write checks.
- Invalid local files are rejected without replacing an existing cache entry.

### Package list clarity

- The localization panel now shows only the package that exactly matches the
  connected device's current firmware by default.
- Other packages for the same hardware are placed behind a collapsed "Other
  Firmware Versions" control and remain informational only.
- Install, download, link-copy, and local-import actions always remain bound to
  the exact current-firmware match.

### Activation guidance

- The completion message and both READMEs now state the complete activation
  sequence: restart the device manually, then open Settings > Language and
  select French to activate the Chinese UI.

## 中文

> 在保留自动安装为默认流程的同时，增加经过严格校验的手动汉化包备用路径，
> 并让汉化列表优先聚焦连接设备当前运行的固件。

### 汉化包备用路径

- “启用中文”仍是首选流程：rmtool 会自动下载、校验并安装与连接设备精确
  匹配的汉化包。
- 成功检测状态后，“获取汉化包”可将匹配的 `.qm` 文件保存到电脑，或复制
  直接下载链接，供网络不稳定时使用。
- “加载本地汉化包”可将此前下载的文件导入 rmtool 现有缓存。文件必须通过
  当前设备对应包的精确字节大小和 SHA-256 校验。
- 导入本地包不会写入设备。之后仍由原有“启用中文”流程完成固件、原始
  载体、字体、备份、部署和写入后校验。
- 无效本地文件会被拒绝，也不会覆盖已有缓存。

### 汉化列表优化

- 汉化面板默认只显示与连接设备当前固件精确匹配的汉化包。
- 同款硬件的其他包折叠在“其他固件版本”中，仅用于查看。
- 安装、下载、复制链接和加载本地包始终绑定当前固件的精确匹配项。

### 启用提示

- 完成提示和中英文 README 已明确完整步骤：手动重启设备，然后进入
  “设置 > 语言”选择“法语”，中文界面才会正式启用。
