# rmtool v1.19.0

## 中文

- 修复拼音输入法卸载时重复获取设备锁而失败的问题。
- 新增统一容量预检，在下载和暂存前发现空间不足，避免无效传输。
- 新增“设备修复与清理”：可明确选择仅保留 home 字体，重新核验后继续原安装；无可信候选或空间仍不足时安全停止。
- 补充 RM1/RM2 根分区空间限制说明，保留完整暂存、回滚保护和安全余量。

## English

- Fix Pinyin uninstall failing because the device operation lock was acquired twice.
- Add unified capacity preflight to detect insufficient space before downloads and staging.
- Add device repair and cleanup with an explicit home-only font option, followed by fresh validation before continuing the original installation; stop safely when no trusted candidate exists or space remains insufficient.
- Document RM1/RM2 root-storage constraints while preserving complete staging, rollback protection, and safety reserves.
