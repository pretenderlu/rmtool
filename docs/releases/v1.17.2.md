# rmtool v1.17.2

## 中文

- 修复 RM1/RM2 部分设备误报空间不足，导致插件安装或修复受阻的问题。
- 优化系统字体的空间检查，空间不足时明确提示所在分区和缺少的容量。

## English

- Fix incorrect low-space warnings blocking plugin installation or repair on some RM1/RM2 devices.
- Improve system-font capacity checks and identify the affected partition and storage shortfall.
