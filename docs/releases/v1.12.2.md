# rmtool v1.12.2

## English

- Reading Enhancements now keeps global authorization in device Settings while
  adding independent per-book controls for tap-to-turn, fast monochrome, and
  forced refresh in each PDF/EPUB reading menu.
- Supported Paper Pro and Paper Pro Move stable and beta firmware can safely
  detect, migrate, repair, or clean exact older reading plugins before a fresh
  install. Other verified rmtool plugins are preserved.
- Forced-refresh controls stay out of notebooks, inserted note pages, and
  non-reading views.

Windows x64 portable and single-file packages, plus the macOS ARM64 application,
are available from GitHub Releases.

## 中文

- 阅读增强继续由设备设置中的总开关统一授权，并在每本 PDF/EPUB 的阅读菜单中
  提供点击翻页、快速黑白和强制刷新的独立单书开关。
- 支持的 Paper Pro 与 Paper Pro Move 正式版、测试版固件现在可以安全检测、
  迁移、修复或清理精确匹配的旧阅读插件，再进行全新安装；其他已验证的
  rmtool 插件会被保留。
- 强制刷新选项不会出现在笔记本、插入笔记页或非阅读页面中。

Windows x64 便携版、Windows x64 单文件版和 macOS ARM64 应用可从 GitHub
Releases 下载。
