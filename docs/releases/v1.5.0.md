# rmtool v1.5.0

## English

> Adds fast monochrome reading with periodic cleanup, safer shared Xovi
> deployment, resilient dual-source downloads, and boot-time Chinese font
> support.

### Fast monochrome reading

- Adds a session-scoped `快速黑白` switch to the PDF/EPUB More menu on exactly
  supported Paper Pro and Paper Pro Move firmware.
- Adds a stock-style `强制刷新` foldout page with cleanup after every 5, 10,
  20, or 30 real page turns, or never. The default is 10; taps and swipes both
  count, and the system full-clear runs after the new page has rendered.
- Publishes eight exact packages covering Paper Pro and Paper Pro Move on
  stable 3.27.1/3.27.3 and beta 3.28.0.162/3.28.0.163. Each package matches the
  hardware, architecture, internal firmware version, and stock xochitl hash.
- Packages remain labelled **offline verified** unless that exact package has
  completed the full enable, disable, restart, and rollback cycle on physical
  hardware.

### Xovi deployment and upgrades

- Standard Vellum/AppLoader installations receive a minimal Vellum package.
  Clean devices use rmtool's own shared Xovi/QRR runtime.
- Tap-to-turn and fast monochrome can coexist. In standalone mode they share
  one authenticated runtime while retaining separate QMD state, so future
  rmtool features can use the same guarded runtime layout.
- Exact fast-monochrome r1/r2 packages are recognized as trusted predecessors
  and can be removed before r3 is installed. Unknown or modified payloads are
  still rejected before a device write.
- Fixes false Vellum/standalone and peer-package detections, including disabled
  markers and devices where tap-to-turn is already managed by Vellum.
- Installation and removal close SSH and require a manual device restart.
  rmtool does not restart xochitl or reboot the tablet automatically.

### Fonts and localization recovery

- Font Management can list uploaded TTF/OTF files, preview them, upload or
  delete inactive fonts, set an exact file as the system UI font, and reapply
  the active font without requiring a second uploaded font.
- Applying or reapplying a font creates a byte-identical rmtool-owned mirror in
  `/usr/share/fonts/ttf/rmtool`, allowing Chinese to render on the passcode
  screen before encrypted `/home` is mounted.
- Font bytes, root-space availability, cache refresh, and system-only
  Fontconfig matching are verified. Failures restore the prior font and
  configuration state.
- Localization restore distinguishes localization-owned font state from a
  font selected later by the user, preserving the latter and retaining exact
  recovery metadata when cleanup cannot finish safely.

### Downloads, builds, and interface

- Application installers and all rmtool-hosted firmware resources now use
  Tencent COS and GitHub sources. The client prefers COS, falls back to GitHub,
  and verifies size and SHA-256 on every manifest and payload response.
- A validated cache and the bundled baseline trusted manifests remain
  available when both sources fail. Firmware-specific payloads are not bundled.
- Release automation builds Windows x64 portable and single-file packages plus
  the macOS ARM64 app, publishes all three to GitHub Releases and Tencent COS,
  and syncs feature assets only after manifest and payload verification.
- Cleans up Device Toolbox heading hierarchy and replaces internal runtime
  terminology in user-facing progress and error messages with clearer shared
  Xovi wording.

### Safety notes

- Exact hardware, firmware, architecture, xochitl, package, path, ownership,
  size, and SHA-256 checks remain mandatory before deployment.
- **Offline verified** means the package passed official-firmware extraction,
  QMLDiff replay, structure, archive, and deterministic-build checks; it does
  not claim complete physical-device validation.
- After localization, font, tap-to-turn, or fast-monochrome changes, wait for
  rmtool to close SSH and restart the device manually when prompted.

## 中文

> 新增快速黑白阅读与周期清屏，完善共享 Xovi 安全部署和双源下载，并让
> 自定义中文字体在锁屏密码界面中也能可靠显示。

### 快速黑白阅读

- 在精确支持的 Paper Pro 和 Paper Pro Move 固件 PDF/EPUB“更多”菜单中增加
  会话级“快速黑白”开关。
- 新增原生样式的“强制刷新”二级页面，可选择每 5、10、20、30 次真实翻页
  清屏一次，或选择“从不”；默认每 10 次，点击和滑动翻页都会计数，并在
  新页面渲染完成后调用系统完整清屏。
- 发布 8 个精确包，覆盖 Paper Pro 和 Paper Pro Move 的 3.27.1/3.27.3 正式版
  及 3.28.0.162/3.28.0.163 测试版；每个包都精确匹配硬件、架构、内部固件
  版本和原始 xochitl 哈希。
- 只有精确包完成真机启用、停用、重启和回滚全流程后才会标注真机验证，
  其余继续明确标注为**官方固件离线验证**。

### Xovi 部署与升级

- 设备已有标准 Vellum/AppLoader 时安装最小 Vellum 包；干净设备则使用
  rmtool 自有共享 Xovi/QRR 运行时。
- 点击翻页与快速黑白可以共存。独立部署模式下二者共享一套经过认证的
  运行时，同时保留各自的 QMD 状态，后续 rmtool 功能也可沿用同一安全布局。
- 可精确识别 rmtool 安装的快速黑白 r1/r2 旧包，先安全移除再升级到 r3；
  未知或被修改的载荷仍会在写入设备前拒绝操作。
- 修复 Vellum 与独立部署误判、功能包相互误判、停用 marker，以及设备已由
  Vellum 管理点击翻页时的检测问题。
- 安装和停用结束后会关闭 SSH，并要求用户手动重启；rmtool 不会自动重启
  xochitl 或设备。

### 字体与汉化恢复

- 字体管理可列出和预览已上传的 TTF/OTF，上传字体、删除未启用字体、按
  精确文件设置系统界面字体，并可在只有一个字体时“重新应用系统字体”。
- 应用或重新应用字体时，会在 `/usr/share/fonts/ttf/rmtool` 建立字节完全
  一致的 rmtool 专用镜像，使加密 `/home` 尚未挂载的锁屏密码界面也能显示中文。
- 操作会校验字体字节、根分区空间、字体缓存和仅使用系统字体的 Fontconfig
  匹配；失败时恢复此前字体与配置状态。
- 汉化还原会区分汉化流程建立的字体状态和用户后来主动选择的系统字体，
  保留后者；无法安全完成清理时会保留精确恢复数据，避免破坏现有字体配置。

### 下载、构建与界面

- 应用安装包及所有 rmtool 托管的固件资源均提供腾讯云 COS 与 GitHub 两个
  来源。客户端优先 COS，失败后回退 GitHub，并逐次校验清单和载荷的大小及
  SHA-256。
- 两个远端均失败时可回退已验证缓存和应用内置基础可信清单；固件专用载荷
  不会打包进应用。
- Release 自动构建 Windows x64 便携版、Windows x64 单文件版和 macOS ARM64
  应用，并发布至 GitHub Releases 与腾讯云 COS；功能资源也会在清单和载荷
  全部验证后自动同步。
- 统一设备工具箱的标题层级，并将进度和错误提示中的内部运行时术语改为更
  清晰的“共享 Xovi 组件”等用户文案。

### 安全说明

- 部署前仍会严格匹配硬件、固件、架构、xochitl、包、路径、所有权、大小和
  SHA-256，不会根据相近版本猜测兼容性。
- **官方固件离线验证**表示已通过官方固件提取、QMLDiff 回放、结构、压缩包
  和确定性构建检查，不代表对应精确包已完成全部真机验证。
- 汉化、字体、点击翻页或快速黑白操作完成后，请等待 rmtool 关闭 SSH，再按
  提示手动重启设备。
