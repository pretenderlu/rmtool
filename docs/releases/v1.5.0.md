# rmtool v1.5.0

## English

This release adds faster black-and-white reading, improves font management and
Chinese UI reliability, and makes reading-feature installation easier to manage.

### What's new

- **Fast monochrome reading:** Supported Paper Pro and Paper Pro Move firmware
  now gets a `快速黑白` switch in the PDF/EPUB More menu for cleaner, faster
  black-and-white page turns.
- **Periodic full refresh:** Choose a full screen refresh after every 5, 10, 20,
  or 30 page turns, or disable periodic refresh. The default is every 10 turns.
- **Reading features can coexist:** Tap-to-turn and fast monochrome reading can
  be installed together. Detection, updates, disabling, and removal are more
  reliable on both Vellum/AppLoader devices and clean devices.
- **Improved font management:** View and preview uploaded fonts, upload or delete
  fonts, set a system font, and reapply the current font even when only one font
  is installed.
- **Chinese on the passcode screen:** The selected Chinese system font is now
  available during startup, preventing square boxes on the lock-screen passcode
  interface.
- **Safer localization restore:** Restoring the original interface no longer
  removes a system font that the user selected separately.
- **Clearer interface:** Device Toolbox headings and operation messages have
  been simplified and made more consistent.

### Downloads

- Windows x64 portable ZIP, Windows x64 single-file EXE, and macOS ARM64 builds
  are available from GitHub Releases.
- Localization, tap-to-turn, and fast-monochrome resources use Tencent COS first
  with GitHub fallback, helping users in different network environments.

### Before using

- Availability is matched to the connected device and exact firmware version;
  rmtool will not install a package intended for a different version.
- After changing localization, fonts, tap-to-turn, or fast monochrome reading,
  wait for rmtool to finish and restart the device manually when prompted.

## 中文

本次更新新增快速黑白阅读，完善字体管理与中文界面显示，并让阅读功能的安装、
升级和停用更加简单可靠。

### 新增与改进

- **快速黑白阅读：** 在受支持的 Paper Pro 和 Paper Pro Move 固件 PDF/EPUB
  “更多”菜单中增加“快速黑白”开关，让纯黑白文字翻页更加利落。
- **周期完整刷新：** 可选择每 5、10、20、30 次翻页后完整刷新一次屏幕，也可
  选择“从不”；默认每 10 次翻页刷新一次。
- **阅读功能可以共存：** 点击翻页与快速黑白可以同时安装，并改善了两项功能在
  Vellum/AppLoader 设备和干净设备上的检测、升级、停用及卸载流程。
- **字体管理完善：** 可以查看和预览已上传字体，上传、删除、设置系统字体；即使
  设备中只有一个字体，也可以重新应用当前系统字体。
- **锁屏密码界面支持中文：** 设备启动过程中也能调用选定的中文系统字体，避免
  锁屏密码界面显示方框。
- **汉化还原更安全：** 还原原始界面时，不会删除用户后来单独设置的系统字体。
- **界面更加清晰：** 统一设备工具箱的标题层级，并简化部分操作进度和错误提示。

### 下载

- Windows x64 便携版、Windows x64 单文件版和 macOS ARM64 版本通过 GitHub
  Releases 提供。
- 汉化、点击翻页和快速黑白资源优先使用腾讯云 COS，连接失败时自动回退 GitHub，
  方便不同网络环境下使用。

### 使用前须知

- rmtool 会根据设备型号和精确固件版本显示可用资源，不会安装其他版本的功能包。
- 汉化、字体、点击翻页或快速黑白操作完成后，请等待 rmtool 结束操作，并按提示
  手动重启设备。
