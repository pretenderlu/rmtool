# rmtool v1.16.18

## 中文

- 修复连续重启后汉化和共享插件无法加载的问题。
- 减少修复完整插件所需的存储空间。
- 修复系统界面未运行时无法修复或停用插件的问题。

遇到插件失效时，请在“旧版插件迁移/清理”中检测恢复状态并执行修复，完成后按提示重启设备。

## English

- Fix Chinese localization and shared plugins failing to load after repeated restarts.
- Reduce storage needed to repair intact plugin installations.
- Allow plugin repair and disable when the system interface is stopped.

If plugins stopped working, detect recovery status under Legacy plugin migration/cleanup, apply the repair, then restart as prompted.
