# rmtool v1.15.11

## 中文

- EPUB 阅读字体改为动态列表，不再限制三个字体；添加、排序和删除均由 rmtool 自动管理。
- Paper Pro Move 3.28.0.172 的阅读增强新增中文划词精确选取，荧光笔可按中文字符边界截断选区。
- 休眠壁纸可保存在用户分区，减少对系统根分区空间的占用。

以上功能参考 [bbq191/rm-tweak](https://github.com/bbq191/rm-tweak) 的实现思路，并按 rmtool 的固件精确匹配、资源校验和回滚机制重新实现。

Windows x64 与 macOS ARM64 应用安装包从 GitHub Releases 提供；更新后的固件功能资源同步发布至 GitHub 与腾讯云 COS。

## English

- EPUB reader fonts now use a dynamic list instead of three fixed slots; rmtool manages insertion order and removal automatically.
- Reading Enhancements on Paper Pro Move 3.28.0.172 adds precise Chinese/CJK highlight selection at character boundaries.
- Sleep wallpapers can be stored on the user partition to reduce root-partition usage.

These features are based on approaches from [bbq191/rm-tweak](https://github.com/bbq191/rm-tweak) and reimplemented with rmtool's exact-firmware checks, resource verification, and rollback model.

Windows x64 and macOS ARM64 application packages are available from GitHub Releases. Updated firmware feature resources are published to both GitHub and Tencent COS.
