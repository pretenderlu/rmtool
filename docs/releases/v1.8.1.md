# rmtool v1.8.1

## English

- Compacted the device connection panel so all navigation items remain visible
  on smaller screens and Windows display scaling.
- Added sidebar scrolling as a fallback for very small windows.
- Removed the obsolete third-party application links from Device Tools.

Windows x64 portable and single-file packages, plus the macOS ARM64 application,
are available from GitHub Releases.

## 中文

- 压缩设备连接区域，在较小屏幕及 Windows 显示缩放下也能完整显示导航项。
- 为更小的窗口增加侧栏滚动兜底。
- 移除设备工具中过时的第三方应用链接说明。

Windows x64 便携版、Windows x64 单文件版和 macOS ARM64 应用可从 GitHub
Releases 下载。
