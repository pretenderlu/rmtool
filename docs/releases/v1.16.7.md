# rmtool v1.16.7

## 中文

- **修复 RM1/RM2 自定义系统字体：** 老设备没有独立 `/data` 分区时，改用实际的根分区检测可用空间，不再因路径不存在而直接失败。
- **适配老设备空间：** RM1/RM2 使用较小的 8 MiB 安全预留，新设备继续保留 24 MiB；设置字体前会提示老设备空间有限，不建议上传过多或过大的自定义字体。
- **优化固件管理提示：** 检测到 RM1/RM2 的旧版分区架构时，不再错误探测 `root_a/root_b`，而是明确提示当前暂不支持 A/B 固件升级、降级和分区切换，并禁用相关操作。

Windows x64 与 macOS ARM64 应用安装包从 GitHub Releases 提供。

## English

- **Fixed custom system fonts on RM1/RM2:** When a legacy device has no separate `/data` mount, rmtool now checks the actual root filesystem instead of failing on the missing path.
- **Added legacy storage safeguards:** RM1/RM2 use an 8 MiB safety reserve while modern devices keep the 24 MiB reserve. Font activation warns that legacy storage is limited and discourages many or oversized custom fonts.
- **Clarified firmware-management limits:** RM1/RM2 legacy partition layouts no longer trigger an incorrect `root_a/root_b` probe. rmtool now explains that A/B firmware upgrade, downgrade, and partition switching are unavailable and disables those actions.

Windows x64 and macOS ARM64 application packages are provided through GitHub Releases.
