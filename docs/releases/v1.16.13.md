# rmtool v1.16.13

## 中文

- **改进中文字体检测：** 检查系统实际匹配到的简体中文字形，减少已内置中文字体却仍提示缺少字体的情况；诊断日志补充字体匹配信息，便于排查中文不显示的问题。
- **修复固件更新后的状态判断：** 已确认完成并重启的更新不再因后续正常系统升级而重新阻止插件、字体等操作；进行中或结果不明的更新仍保留安全保护。
- **加强文档与书库操作保护：** 防止异常文档标识扩大删除范围；KOReader 操作绑定发起时的设备，避免切换设备后误操作。传输中断或校验失败时保留原文件。
- **改善刷新与诊断：** 固件状态刷新继续跟踪进行中的任务，清理批量操作的临时文件，并更准确地记录设备命令失败和日志截断。
- **更新兼容性说明：** 中英文 README 列出五款设备、正式版与测试版固件，以及各插件的实际覆盖范围。未开放的设备功能明确提示，不再把设备支持等同于所有插件通用。

本次为应用修复，不新增设备、固件或插件适配。3.28.0.172 的原生中文与拼音支持五款设备；阅读增强、笔记增强、EPUB 字体菜单、微信读书入口和固件管理目前仅开放 Paper Pro / Paper Pro Move。Pure、RM1、RM2 提供独立点击翻页。AppLoad / KOReader 在 rmtool 中仍只开放已适配的 3.27 正式版安装。

Windows x64 与 macOS ARM64 安装包见下方附件。固件专用资源沿用现有在线资源，无需重复安装已正常工作的插件。

## English

- **Improved Chinese font detection:** Check the actual Simplified Chinese font match and glyph coverage, reducing false missing-font prompts on devices with usable stock Chinese fonts. Diagnostics now include font-match information.
- **Fixed firmware completion tracking:** A confirmed, rebooted update no longer blocks plugins, fonts and other operations after a later normal system upgrade. Active or uncertain updates retain their safety guards.
- **Safer document and library operations:** Invalid document identifiers cannot widen deletion scope. KOReader operations remain bound to the originating device across connection changes. Interrupted or invalid transfers preserve existing files.
- **Improved refresh and diagnostics:** Firmware refresh continues tracking active tasks, batch operations clean up temporary files, and diagnostics more accurately report device command failures and truncated output.
- **Updated compatibility documentation:** Both README languages list all five devices, stable and beta firmware, and the actual feature coverage. Unsupported device functions are explicitly distinguished from generic device support.

This application patch adds no device, firmware or plugin ports. On 3.28.0.172, native Chinese and Pinyin cover all five devices; reading enhancements, note enhancements, EPUB font menus, the WeRead launcher and firmware management remain limited to Paper Pro / Paper Pro Move. Pure, RM1 and RM2 have standalone tap-to-turn. AppLoad / KOReader installation in rmtool remains limited to supported 3.27 stable builds.

Windows x64 and macOS ARM64 packages are available below. Existing online firmware resources are unchanged; working plugins do not need to be reinstalled.
