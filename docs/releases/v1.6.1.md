# rmtool v1.6.1

## English

- Fixed switching from an existing custom system font to another uploaded
  font. The previous active font no longer causes the new font to be rejected
  by mistake.
- Preserved the existing transactional checks and rollback protection for the
  `/data` font mirror and passcode-screen font support.

Feature resources and manifests are unchanged in this patch. Windows x64 and
macOS ARM64 application downloads are available from GitHub Releases.

## 中文

- 修复已有自定义系统字体时无法切换到另一款已上传字体的问题，旧字体的配置不再导致新字体被误判为失败。
- 保留 `/data` 字体镜像、锁屏密码界面字体支持，以及原有的完整校验和失败回滚保护。

本次补丁未改动功能资源和清单。Windows x64 与 macOS ARM64 应用安装包仍通过 GitHub Releases 发布。
